Titanic Survival Analysis
Project Overview

This project performs Exploratory Data Analysis (EDA) on the Titanic dataset to understand survival patterns and passenger characteristics. The analysis focuses on demographic features, ticket class distribution, fare patterns, and statistical summaries.

Objectives

Analyze survival distribution

Study impact of gender, age, and passenger class on survival

Perform descriptive statistical analysis

Visualize key insights using data visualization techniques

Technologies Used

Python

Pandas

Seaborn

Matplotlib

SciPy

Dataset

The dataset used is the Titanic dataset available in Seaborn.

Key Analysis Performed

Data cleaning and preprocessing

Descriptive statistics

Survival rate comparison

Visualization of categorical and numerical features

How to Run

Open the Jupyter/Colab notebook.

Install required libraries if needed.

Run all cells to reproduce the analysis.
